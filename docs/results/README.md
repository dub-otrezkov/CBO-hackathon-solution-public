# Таблицы результатов по записям

Таблицы получены нашим стендом на коде из `src/` (как он устроен, описано в разделе 2, итоги — в разделе 5). Каждая запись проигрывалась в реальном времени через `ros2 bag play` в отдельном контейнере без сети. Нода запускалась штатной командой `ros2 launch tram_odometry tram_odometry.launch.py`, ей выделялись 2 ядра и 512 МиБ памяти, GNSS был доступен только первые 5 с. Эталон: GNSS антенны master в системе судьи (UTM 37N со сдвигом −300 000 м по E и −6 100 000 м по N), перенесённый в точку `base_link` по TF организаторов.

| Файл | Что внутри |
|---|---|
| `validation.md` | 21 запись 26.08.2026, оба вагона, целиком |
| `test.md` | 4 записи 03.09.2026, отложенные до конца; в этот день GNSS хуже, у датчиков колёс масштаб сдвинут примерно на 1 % |
| `research.md` | 7 реальных эпизодов проскальзывания и юза из записей validation |
| `faults.md` | 2 записи, первые 300 с, 12 видов внесённых сбоев |

В каждом файле сначала идёт строка медиана / 90-й процентиль по сценарию, затем строка на каждую запись. Все 56 прогонов прошли все проверки с первой попытки.

Эталон GNSS со статусом RTK тоже иногда неверен: антенна master прыгает на десятки метров. На такие эпохи приходится около 75 % суммы квадратов ошибки XY на validation и test, поэтому главное в таблицах — медиана по записям.

## Колонки

| Колонка | Смысл |
|---|---|
| `vel_rmse` | RMSE скорости относительно доплеровской скорости GNSS master, м/с; выход и эталон сопоставляются по `header.stamp` с допуском 0.05 с |
| `vel_rmse_post_init` | то же после окна GNSS (первых 5 с) |
| `vel_rmse_clean_ref` | то же без моментов, где эталон ненадёжен: два приёмника расходятся больше чем на 0.5 м/с или метка GNSS сдвинута больше чем на 0.3 с |
| `vel_bias` | среднее «выход минус эталон», м/с |
| `vel_matched` | доля выходов, для которых нашлась скорость эталона |
| `focus_rmse` | RMSE скорости в окне эпизода проскальзывания, м/с (только `research.md`) |
| `final_drift_xyz_pct` | 3D-ошибка положения в конце записи, % от пути по GNSS |
| `xy_rmse`, `xyz_rmse` | RMSE положения по XY и в 3D в системе судьи, м |
| `xy_rmse_rtk` | RMSE по XY только по эпохам эталона с RTK (решение с поправками базовой станции) |
| `xy_med` | медиана ошибки XY по эпохам, м |
| `rate_vel_hz`, `rate_pos_hz` | частота `/result/velocity` и `/result/position`, Гц |
| `lat_p95_ms`, `lat_max_ms` | задержка от прихода входа до прихода выхода с той же меткой, 95-й процентиль и максимум, мс |
| `cpu_p95` | загрузка процессора нодой, 95-й процентиль, ядра |
| `rss_max_mib` | максимум памяти ноды (RSS), МиБ |
| `failed_checks` | число проваленных проверок требований (задержка, частота, ресурсы, контракт топиков) |
